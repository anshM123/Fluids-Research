### R014 — P02: why continuation stalled near the sonic limit, and the fix (layer pinning)
- **Diagnosis.** Beyond λ≈0.458 all λ-free continuations (Krylov/dense arclength, p- and δ-continuation) stalled. SVD of the fixed-λ Jacobian at λ=0.458: σ_min = 2.1e−3 with a right singular vector localised in the sonic layer (a *translation* of the layer); the δ-bordered system has σ_min = 2.4e−4 because min(den) is translation-invariant to first order (bordering row · null vector = −6e−4). The previous arclength norm (weights ∝ dη) gave the layer ≈ zero weight.
- **Fixes.** (i) `ccf_sinhgrid.py`: geometric (sinh-type) grid map dη/ds = cosh u/(cosh u + k): spacing h_c at the layer, ∝ distance from the layer up to O(1), h_s far away (the tanh map refined only the central ~15 % of the layer). (ii) `pinned_delta.py`: the scaling symmetry Θ→κΘ(ξ/κ) (= translation in η) is used to PIN the minimum of den at the grid centre (row F_{i0} = den_{c+1} − den_{c−1}, replacing the far-field normalisation); δ = den_c is then a regular parameter. Newton converges quadratically (7e−6 → 5e−7 → 1e−11 → 2e−13) and δ can be reduced by 20–50 % per step.
- **Status:** VERIFIED (method); resolution checks by re-gridding: λ changes ≤ 7e−9, p ≤ 3e−8.

### R015 — P02: structure of the sonic limit (square-root cusp)
- **Observation** (λ≈0.4568, δ=0.011; `layer_shape.py`): den/δ at distance X·w from the minimum grows like X^{1/2} (right flank 4.1, 9.9, 22.6, 50.5 at X=4,16,64,256), not like 1+X²; ln Θ − ln Θ_s ∝ ±|x|^{0.5} on both sides; the layer width scales as **w = 9.05 δ²** (w/δ² = 9.085, 9.052, 9.086 at δ = 8.3e−3, 5.3e−3, 2.7e−3).
- **Explanation (derived).** At a sonic point den = 0 the profile equation ξΘ' den = λΘ and the Hilbert transform close on a square-root singularity: if Θ ≈ Θ_s + B sgn(ξ−ξ_s)|ξ−ξ_s|^{1/2} then H maps it to B|ξ−ξ_s|^{1/2} (H[sgn|x|^{1/2}] = |x|^{1/2}), so den ≈ (B/ξ_s)|ξ−ξ_s|^{1/2}, and the ODE returns the same singularity iff **B² = 2λΘ_s**. For δ>0 the cusp is regularised on the scale w ∝ δ² (den ≈ δ + k|x|^{1/2}). The branch therefore terminates at a *cusp profile* with an interior square-root singularity (λ*, p*); the jump of ln Θ across the layer stays finite, so the terminal profile is continuous.
- **Consequence.** The ladder on this branch is finite: the number of smooth profiles = number of p=2 crossings before the cusp end. Corrections expected ∝ δ ln(1/δ) (logarithmic matching of the |x|^{-1/2} layer integrand).
- **Status:** DISCOVERY (structure), quantitative p*, λ* in progress.

### R023 — P03: classical solver for 2D Boussinesq self-similar profiles (log-polar Newton–Krylov)
- Formulation: exact stagnation-point structure factored out (Θ = cos^m β Θ̂), march in s = ln r from the local solution,
  spectral Biot–Savart, unknown X = Ψ/r². Two numerical pitfalls removed: FFT-derivative Gibbs contamination of the Jacobian
