# Fluids Parallel Discovery Program

Autonomous computational fluid-dynamics research program (target: a genuinely new, positive,
computationally established result). Layout:

- `ledger/IDEAS.md` — idea registry (IDEA001…), triage status
- `ledger/RLOG.md` — research log of experiments/deductions (R001…)
- `ledger/PORTFOLIO.md` — live tiers & compute allocation
- `literature/` — literature death-audit notes
- `tools/` — shared, verified solvers (`ps2d.py` 2D pseudo-spectral NS; `channel2d.py` 2D channel
  Fourier×Legendre-Galerkin; `qtt.py` tensor-train analysis)
- `programs/Pxx_*` — per-program code and results
- `dossier/` — publication materials for the leading result
